# D2D_modify

Direct2D 기반의 자체 제작 게임 엔진(`Engine`)과, 그 위에서 동작하는 로컬 2인용 대전 게임(`D2DProject`)입니다.

## 프로젝트 구성

| 폴더 | 설명 |
| --- | --- |
| `Engine` | 씬 관리, 오브젝트/컴포넌트, 충돌 처리(AABB, BoxCollider), 리소스/입력/시간 관리를 담당하는 자체 엔진 |
| `D2DProject` | 엔진을 사용해 만든 실제 게임 (플레이어, 공, 스코어, 씬 전환 등) |

## 실행 방법

1. `D2DProject.sln`을 Visual Studio 2022로 엽니다.
2. 플랫폼을 `x64` 또는 `x86`, 구성을 `Debug` 또는 `Release`로 설정합니다.
3. `D2DProject`를 시작 프로젝트로 지정하고 빌드/실행합니다.

## 조작 방법

- `F1`, `F2` : 화면(씬) 전환
- 왼쪽 플레이어 : `W` (점프), `A` / `D` (이동)
- 오른쪽 플레이어 : 방향키 (`←` `→` 이동, `↑` 점프)

## 개발 현황

아직 개발 중인 프로젝트이며, 지속적으로 기능을 수정·보완하고 있습니다.
